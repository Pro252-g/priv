# IEP0.4 — النشر

المرجع العملي الموحد هو [دليل التنفيذ الكامل](EXECUTION_GUIDE.md): تجهيز Ubuntu24.04، تنزيل فرع iep-pilot، Docker/Compose، نطاق وHTTPS، أسرار خاصة، volumes، عامل المطعم وRTSP، الفحص والخدمات والنسخ والاستعادة.

[ملف المشروع](PROJECT_REVIEW.md) يوضح ما نُفذ وما اختُبر وما يحتاج قبولًا ميدانيًا. [متطلبات الكلود](CLOUD_REQUIREMENTS.md) و[السعة](CAPACITY_AND_OPERATIONS.md) يحددان الموارد وحدود الاستقراء.

ملفات deploy قوالب قابلة للتنفيذ؛ لا توجد استضافة عامة أو نطاق اشتراه العميل أو شهادة عامة اختُبرت خلال هذه المهمة. localhost للتحقق الداخلي فقط. نشر إعداد بيئة Codex لا ينشر الموقع.

لا تنشر NVR أو منفذ3000 أو DB أو الصور الخام للإنترنت؛ النشر عبر Caddy HTTPS وAPI بمستخدم غير جذر وvolumes خاصة، والمطعم يرسل النتائج عبرHTTPS صادر.
